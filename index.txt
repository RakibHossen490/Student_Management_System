# University Management System - Complete Implementation Plan & Description

## Project Overview
A comprehensive Flutter mobile application for university/college management with Firebase backend integration. The system supports dual user roles (Admin & Student) with complete CRUD operations, file management, attendance tracking, and modern UI with dark/light theme support.

## Architecture & Technology Stack

### Frontend
- **Framework**: Flutter (Latest Stable)
- **Language**: Dart
- **UI Framework**: Material Design 3
- **State Management**: Provider Pattern
- **Theme System**: Dynamic Dark/Light Mode with Persistence

### Backend & Services
- **Authentication**: Firebase Auth
- **Database**: Cloud Firestore
- **File Storage**: Firebase Storage
- **Real-time Updates**: StreamBuilder for Live Data

### Key Dependencies

## Feature Implementation Details

### 1. Authentication System
**Admin Login:**
- Email/password authentication
- Role verification in Firestore
- Automatic logout for unauthorized access

**Student Login:**
- Name + Student ID + Phone + Department
- Auto-creation of Firebase Auth account
- Profile data stored in Firestore

### 2. Student Management (Admin Only)
**CRUD Operations:**
- Add new students with department/semester
- Edit existing student information
- Delete students with confirmation
- Table view with search/filter capabilities

**Data Fields:**
- Name, Student ID, Email, Phone
- Department, Semester
- Profile Image (optional)

### 3. Attendance System
**Admin Features:**
- Select Department → Semester → Student
- Mark daily attendance (Present/Absent)
- View attendance history with percentages
- Monthly attendance tracking

**Student Features:**
- View personal attendance records
- See attendance percentage by month
- Real-time updates from Firestore

**Calculation Logic:**
```dart
final totalDays = 30; // Assuming 30 days per month
final percentage = (attendedDays / totalDays) * 100;
```

### 4. File Management System (Results, Syllabus, Routine)
**Upload Features:**
- File picker for PDF, DOCX, Images
- Firebase Storage integration
- Metadata storage in Firestore
- Progress indicators during upload

**File Organization:**
```
/results/{semester}/{subject}/{timestamp}_{filename}
/syllabus/{semester}/{subject}/{timestamp}_{filename}
/routine/{semester}/{timestamp}_{filename}
```

**Student Access:**
- View all uploaded files by department/semester
- Download files to device
- File type icons (PDF, DOC, Image)

### 5. Profile Management (Students)
**Features:**
- View personal information
- Upload profile image to Firebase Storage
- Image persists permanently
- Real-time profile updates

### 6. Theme System
**Implementation:**
- Provider-based state management
- SharedPreferences for persistence
- Toggle button in AppBar (sun/moon icon)
- Automatic theme switching across all screens

**Theme Configuration:**
```dart
Light Theme: Blue primary, white backgrounds
Dark Theme: Blue primary, dark backgrounds (#121212, #1E1E1E)
```

## Firebase Configuration

### Firestore Collections
```
users/           - User profiles with roles
students/        - Student master data
attendance/      - Attendance records
results/         - Exam results with file URLs
syllabus/        - Course syllabus with file URLs
routine/         - Class routine with file URLs
```

### Storage Buckets
```
profile_images/  - User profile pictures
results/         - Result documents
syllabus/        - Syllabus documents
routine/         - Routine documents
```

### Security Rules Required
```javascript
// Firestore Rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /students/{studentId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 0;
    }
    // Similar rules for other collections
  }
}

// Storage Rules
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /profile_images/{userId}/{allPaths=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /results/{allPaths=**} {
      allow read: if request.auth != null;
      allow write: if request.auth != null &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 0;
    }
    // Similar rules for syllabus and routine
  }
}
```
